# Kripali_Bhatt_ML_1701

## Air Quality Index (AQI) Analysis and Machine Learning

This project focuses on analyzing Air Quality Index (AQI) data using Python. It combines data exploration, visualization, preprocessing, and machine learning techniques to identify patterns and build a predictive model using air-quality data.

## Project Objective

The objective of this project is to analyze air-quality data, understand relationships between different pollution indicators, and apply machine learning techniques to develop a data-driven prediction model.

## Project Workflow

The project follows these major steps:

1. Load and explore the AQI dataset.
2. Perform data cleaning and preprocessing.
3. Analyze the distribution of air-quality variables.
4. Visualize important relationships and patterns.
5. Prepare the data for machine learning.
6. Split the data into training and testing sets.
7. Train a machine learning model.
8. Evaluate model performance.
9. Analyze the results and observations.

## Machine Learning Skills Demonstrated

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Data visualization
* Feature selection
* Train-test split
* Machine learning model training
* Model evaluation
* Interpretation of results

## Data Analysis

The analysis focuses on air-quality variables such as:

* AQI
* PM2.5
* PM10
* City/location information
* AQI categories

The project explores relationships between pollution indicators and overall air quality.
